# AI Job Application Tracker

This repository will document the step-by-step build of an AI-powered job application tracker.

### Why this project
Tracking job applications is messy and manual.  
Resumes get rejected without feedback.  
I’m building this to explore how AI can help improve both.

### Build journey
- Day 1: Intent and project setup
- Day 2: Problem definition
- Day 3: Initial UI and data model
- Day 4: AI prompt design
- Day 5: Resume analysis MVP

This project is being built in public.
