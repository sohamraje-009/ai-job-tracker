# AI Job Application Tracker

This repository documents the step-by-step development of an AI-powered job application tracker, built in public.

---

## Why this project

Tracking job applications is often messy and manual.  
Applications are spread across emails, spreadsheets, and multiple job portals, and resumes frequently get rejected without clear feedback.

This project is being built to explore how AI can bring clarity and structure to the job application process by:
- Organizing job applications in one place
- Reducing manual tracking
- Providing insights into resume quality
- Helping identify areas for improvement

---

## Build journey

This project is being developed incrementally, with each stage documented openly.

- **Day 1:** Intent and project setup  
- **Day 2:** Problem definition and user pain points  
- **Day 3:** Initial UI and data model  
- **Day 4:** AI prompt design and experimentation  
- **Day 5:** Resume analysis MVP
