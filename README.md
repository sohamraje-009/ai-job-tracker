# AI Job Application Tracker :

This repository documents the step-by-step development of an AI-powered job application tracker, built in public.

The project explores how AI can be applied in a **practical, explainable, and responsible way** to improve the job application experience for developers.



## Why this project :

Tracking job applications is often messy and manual.  
Applications are scattered across emails, spreadsheets, and job portals, and resumes are frequently rejected without meaningful feedback,

This project was built to address those issues by:
- Centralizing job application tracking
- Reducing manual effort
- Providing clarity on resume strengths and gaps
- Applying AI to solve a real, personal problem rather than adding AI for hype



## Build journey:

This project was developed incrementally as part of a build-in-public journey.

- **Day 1:** Intent, scope definition, and repository setup  
- **Day 2:** Problem definition and user pain points  
- **Day 3:** Initial frontend UI and job tracking functionality  
- **Day 4:** Resume upload and AI-based resume analysis  
- **Day 5:** Final polish, documentation, and project positioning

## AI usage

The AI component focuses on **explainable and actionable feedback**.

For each resume, the AI:
- Identifies key strengths
- Highlights missing or weak skills
- Provides clear suggestions for improvement

The goal is to help users understand *why* changes are needed, rather than relying on opaque scoring systems.
