# AI Job Application Tracker

This repository documents the step-by-step development of an AI-powered job application tracker, built in public.

---

## Why this project

Tracking job applications is often messy and manual.  
Applications are scattered across emails, spreadsheets, and multiple job portals, and resumes are frequently rejected without clear feedback.

This project explores how **AI can bring clarity and structure** to the job application process by:
- Organizing job applications in one place  
- Reducing manual tracking  
- Providing meaningful resume feedback  
- Helping candidates identify improvement areas  

---

## Build journey

This project is being developed incrementally, with each stage documented openly.

- **Day 1:** Intent and project setup  
- **Day 2:** Problem definition and user pain points  
- **Day 3:** Initial UI and job tracking functionality  
- **Day 4:** Resume upload and AI-based resume analysis  
- **Day 5:** Resume analysis refinement and MVP polish

## AI usage

The AI component focuses on **explainable and actionable feedback** rather than opaque scoring.

Current AI capabilities:
- Identify resume strengths  
- Highlight missing or weak skills  
- Provide specific suggestions for improvement  

The goal is to help users understand *why* changes are needed, not just *what* to change.
